# Roadmap

## First release: Ark
Native menu bar quota and resource monitoring; five-minute refresh; Keychain Settings; public GitHub repository with daily work on dev and milestones on main; Homebrew release and final daily-use installation.

## Later providers
Alibaba Cloud Model Studio, MiniMax, Tencent Cloud.

Provider-specific credential and read-only API contracts must be researched and verified before adding support. Do not infer token totals from percentage-only quota APIs, combine different units, or send inference requests to measure quota.

## Release verification still required
Real account data for every displayed Ark section; Keychain save/reopen; actual menu interactions; public release asset; Homebrew install; remove development builds after the Homebrew app is verified running.
